# 文档索引

本项目仍处于早期设计与讨论阶段。根目录的[设计草案](../novel_harness_design.md)是当前讨论入口，尚未形成正式定版的设计规范。

## 阅读顺序

1. [项目 README](../README.md)：了解项目目标与当前已有内容。
2. [设计草案](../novel_harness_design.md)：先读第 1、2 节了解定位与用户流程，再按需要查阅技术细节。
3. 草案第 7、8 节：了解阶段设想、待验证事项与待确认参数。
4. 需要追溯某项提议的来源时，再查阅下表中的历史材料。

## 维护方式

- 当前方案讨论统一更新根目录的 `novel_harness_design.md`，避免同时维护多个“最新版”。
- 历史快照和评审正文保留原貌；后续更正另行记录，并注明所依据的材料。
- 新的评审或实验记录使用描述性名称与日期，如 `主题-YYYY-MM-DD.md`，注明对象、范围、证据与待确认事项。
- Git 已承担日常修改历史；无需为每次文字修改再复制一份带版本号的全文备份。
- 新增或移动文档时同步维护本索引及引用链接。更多约定见 [AGENTS.md](../AGENTS.md)。
